## 🧭 Engineering Philosophy

> *"Bridging the gap between empirical machine learning research papers and high-performance, accessible, production-grade web systems."*

Modern software development often suffers from a divide: data science prototypes remain trapped in isolated Jupyter notebooks, while frontend web applications rarely take advantage of on-device neural acceleration and browser-native inference. This portfolio showcases projects that span this entire spectrum:

- **Mathematical Foundations**: Implementing loss functions, backpropagation dynamics, cycle-consistency formulations, and statistical hypothesis testing from first principles.
- **Production Performance**: On-device WebGPU/WASM inference pipelines, Web Workers, client-side streaming, and server-side rendering for sub-second user latency.
- **Design Systems & Accessibility**: Authored and published `@aryan_sehgal/forma-ui` on npm, implementing Radix primitives with semantic design tokens and strict WCAG 2.1 AA accessibility standards.

### 2. Empirical Machine Learning Case Studies (11 Notebooks)

An interactive, filterable research suite covering classical ML, time-series forecasting, unsupervised clustering, anomaly detection, and recommendation algorithms:

- **IPL Match Analytics (2008–2024)**: Cleaned and engineered 1,095 matches across 20 features. Trained Logistic Regression, KNN, Decision Tree, Random Forest, AdaBoost, XGBoost, and a Voting Ensemble. Mathematically proved that winning the coin toss provides zero statistically significant outcome advantage (50.6% win rate).
- **E-Commerce Marketing & Sales RFM Analysis**: Unified five transactional datasets, performed K-Means customer segmentation, retention cohort heatmaps, and marketing-spend elasticity modeling.
- **Vehicle CO₂ Emissions Predictive Modeling**: Multicollinearity elimination via Variance Inflation Factor (VIF < 5), polynomial regression, and permutation feature importance ($R^2 \approx 0.98$).
- **Time-Series Forecasting**: Compared ARIMA, SARIMAX with exogenous covariates, Holt-Winters Exponential Smoothing, and Facebook Prophet with seasonal decomposition.
- **Unsupervised Clustering Benchmark**: Comparative analysis between K-Means, Agglomerative Hierarchical Clustering, Gaussian Mixture Models (GMM with BIC/AIC), and DBSCAN density clustering.
- **Outlier & Anomaly Detection**: Evaluated IQR statistical trimming, Elliptic Envelope, Isolation Forest, and Local Outlier Factor (LOF) on multi-dimensional distributions.
- **Ensemble Decision Methods**: Systematic benchmark of Bagging (Random Forest), Gradient Boosting (GBDT), XGBoost, and LightGBM hyperparameter optimization.
- **Probabilistic Text Classification**: Multinomial Naive Bayes with TF-IDF vectorization and Laplace smoothing for spam/sentiment classification.
- **Collaborative Filtering & Matrix Factorization**: User-item recommendation engine using stochastic gradient descent (SGD) matrix decomposition and cosine similarity.

Each case study in the portfolio features an **interactive research viewer modal** detailing problem formulation, mathematical equations, algorithm comparison tables, and direct links to reproducible GitHub Jupyter notebooks.

## 🛠️ Tech Stack & Architecture

### Frontend & UI Architecture
- **Framework**: React 19, TypeScript (Strict Mode)
- **Styling**: Tailwind CSS v4 with custom font pairings (`Newsreader` serif display + `Plus Jakarta Sans` body + `JetBrains Mono` code metrics)
- **Component Library**: `@aryan_sehgal/forma-ui` (Aryan's published accessible React design system)
- **Animations**: `motion` (v12) layout animations, hardware-accelerated transitions
- **Icons**: `lucide-react`
- **Tooltips & Accessibility**: Custom portal-based, collision-detecting tooltip system rendered into `document.body` to eliminate viewport overflow and prevent dialog horizontal scrollbars.

### Edge AI, Machine Learning & Data
- **Inference Runtimes**: ONNX Runtime Web, ONNX Runtime CPU
- **Models**: Whisper (speech transcription), FLAN-T5 (summarization & action items), StyleFAT (GAN anime translation), OpenCV DNN (colorization)
- **ML Tooling**: Python 3.10+, TensorFlow/Keras, PyTorch, scikit-learn, XGBoost, LightGBM, statsmodels, pandas, NumPy, Jupyter

### Build, Tooling & Delivery
- **Bundler & Server**: Vite 8, Express 4 / Node.js
- **Static Assets**: Automated PDF generation script (`scripts/build-pdfs.js`) ensuring authentic LoR and Resume static assets are compiled into `public/` and `dist/`.
- **Code Quality**: TypeScript strict type-checking (`tsc --noEmit`), automated linting.

## 🚀 Getting Started

### Prerequisites
- **Node.js**: `v20.0.0` or higher
- **npm**: `v10.0.0` or higher

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/AryanSehgal/portfolio.git
   cd portfolio
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Generate static PDF assets and start the local development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

---

## 📦 Production Build & Testing

1. **Type Checking & Linting**:
   ```bash
   npm run lint
   ```

2. **Production Build**:
   ```bash
   npm run build
   ```
   This compiles the static assets, executes `scripts/build-pdfs.js` to ensure the authentic resume and LoR PDFs are bundled in `dist/`, and runs Vite production minification.

3. **Preview Production Build**:
   ```bash
   npm run preview
   ```

## ♿ Accessibility & UX Standards

This portfolio is engineered in strict conformance with **WCAG 2.1 AA** standards:
- **Keyboard Navigation**: Complete tab indexing, visible focus rings, and `Escape` key listeners on all interactive modals and drawers.
- **Scrollbar Isolation**: Modals feature `overflow-x: hidden` and portal-mounted tooltips to guarantee zero horizontal scrollbar bleeding across any viewport size.
- **Screen Reader Support**: Semantic HTML5 landmark tags (`<main>`, `<nav>`, `<section>`, `<article>`, `<header>`, `<footer>`), `aria-labelledby`, `aria-describedby`, and informative `aria-label` tags on all icon controls.
- **Color Contrast**: Complies with minimum 4.5:1 contrast ratios for all body text in both light and dark modes.
